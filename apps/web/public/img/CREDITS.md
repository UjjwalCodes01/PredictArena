# Photography credits

All photographs in this directory are from [Unsplash](https://unsplash.com) and are used under the
[Unsplash License](https://unsplash.com/license), which permits free use — including commercially —
without permission.

Attribution is not required by that licence. It is given here anyway, because a project that lists
where its assets came from is easier to trust than one that does not.

Files are served from `public/img/` rather than hotlinked, so the site does not depend on a
third-party CDN being reachable during a demo.

Player avatars are **not** photographs: they are SVG identicons generated deterministically from
each wallet address (`components/Avatar.tsx`). No upload, no moderation surface, no external
service.
